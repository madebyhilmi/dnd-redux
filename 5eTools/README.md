# 5e.tools Imports

## Files

- [[5eTools/Wayhouse Campaign - Bestiary.json|Wayhouse Campaign — Bestiary]] contains the custom 2024 creatures and NPCs.
- [[5eTools/Wayhouse Campaign - Hive Assault.encounter.json|Wayhouse Campaign — Hive Assault]] is an Encounter Builder save for three level-5 characters.

## Import order

1. Open **Manage Homebrew** in 5e.tools and import `Wayhouse Campaign - Bestiary.json`.
2. Open the Bestiary and enter **Encounter Builder**.
3. Use the Encounter Builder upload/load-from-file control and select `Wayhouse Campaign - Hive Assault.encounter.json`.

The encounter includes one Dream Wolf, one Memory Hive Bulwark, and one Memory Hive Whisper. Memory hounds are summoned during play and are therefore not preloaded in the roster.

## Included stat blocks

- Mucnir, Dream Wolf
- Memory Hive Bulwark
- Memory Hive Whisper
- Memory Hound Manifestation
- Dumphey
- Mochito Ruriki
- Ebimacha Dokichi

The encounter uses the 2024 rules mode and is tuned as a hard/high-difficulty battle for three level-5 characters.
